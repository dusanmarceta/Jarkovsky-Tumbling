# TEMPEST-Yarkovsky

This repository is a modified version of [TEMPEST](https://github.com/duncanLyster/TEMPEST) by Duncan Lyster, Howett, and Penn.

This version contains substantial modifications and extensions for the calculation of the Yarkovsky effect for tumbling and non-principal-axis rotating asteroids, developed by Dušan Marčeta and contributors.
